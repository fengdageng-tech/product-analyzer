## 需求来源（用户三点）
1. 利润逻辑改为公司 ML2 参考表（`Desktop/kxb/产品利润ML2参考表.xlsx`）的欧洲站口径
2. 采购成本处增加「是否定制」：公模填成本算利润；定制不填成本
3. 网页不再自动给「能做/暂缓/不做」结论 → 改为「我的判断」由用户手标
4. 补充：利润核算不出来时（定制无成本），自动标「暂缓」

## 决策记录
- 站点：完全按欧洲站（€、含增值税、头程按公斤）
- 方案：全套 ML2 指标 + 定制品成本红线
- 利润率颜色门槛：≥15% 绿 / 10–15% 黄 / <10% 红
- 税点：国家下拉（德19/法20/意22/西21），默认德国
- BM 固定 0.22（原表意/西 sheet 的 1.22 是笔误，导致保底价为负，不采用）
- 旧演示数据删除；localStorage key 升级 v2；云端 data.json 清空重推

## 公式（与 ML2 表逐列对应）
| 指标 | 公式 |
|---|---|
| 人民币总成本 TU | KG×头程单价 + 采购价 |
| 成本 CB € | TU ÷ 汇率 |
| 利润 ML € | 售价 − 15.4%×售价 − CB − FBA配送 − 售价×税点/(1+税点) |
| 利润率 ML2 | ML ÷ 售价 |
| 人民币毛利 HB | 售价×ML2×汇率 |
| 成本回报倍数 HB2 | HB ÷ TU |
| 保底价格 | (CB+配送) ÷ (0.846 − 税点/(1+税点) − 0.22) |
| 保底价促销ACOS | (售价−5%售价−15.3%售价−95%×售价×税点/(1+税点)−CB−配送−0.5) ÷ 售价 |
| 30%ACOS促销价 | (CB+配送+0.5) ÷ (1 − 5% − 15.4% − 95%×税点/(1+税点) − 0.22) |
| 参考广告出价 | ML ÷ 10 |
| 定制成本红线 ¥ | (售价×(0.846−税点/(1+税点)) − 配送 − 售价×目标利润率) × 汇率 − KG×头程单价（负数→提示售价过低） |
